## 🔧 Troubleshooting (If Something Goes Wrong)

You probably won't need this section, but it's here to help.

### The App Doesn't Open?

- Make sure you double-clicked the downloaded file and clicked "Run" if prompted.
- Check your Downloads folder – some browsers block direct opening. If so, right-click the file and choose "Open".
- If you get a "Windows protected your PC" message, click "More info" then "Run anyway". This is normal for new tools.

### The Overlay Doesn't Appear in My Game?

- Make sure your game uses **DirectX 11**. This tool is built specifically for that. Most modern games do, but older ones might not.
- Press `Shift + O` a few times to toggle the panel on and off.
- Close other overlay tools (like Discord or Steam overlay). They sometimes conflict.

### My FPS Dropped Slightly?

This is unlikely, but if you notice a small change, simply lower the overlay's opacity or disable the FPS counter. The tool is lightweight, but every little bit helps on older PCs.

### I Forgot My Shortcuts?

Press `Shift + O` to open the main panel. At the bottom, you'll see a button that says "Show Shortcuts". Click it to see the full list anytime.
